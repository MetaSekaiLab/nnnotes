nnnotes 0.2.0 is one pure Python wheel. The deck model of `music-data` is the package `ournotes-sim` of ournotes-deck 0.0.7, installed with `pip install 'nnnotes[deck]'`.

- **Install.** `pip install nnnotes` installs a `py3-none-any` wheel on every platform; building from source needs no Rust toolchain. `pip install 'nnnotes[deck]'` adds the deck model, `ournotes-sim==0.0.7`, a wheel that ournotes-deck publishes for Linux (x86_64, aarch64), Windows (x64) and macOS (x86_64, arm64). Without it, `music-data` names the extra and `--no-deck`. The extension module `nnnotes._deck` no longer exists; `provenance.deck` keeps its fields (`name`, `version`, `source`, `commit`, `sourceSha256`, `format`) and names the 0.0.7 release.
- **Chart statistics.** Each chart's expectations use independent nominal lottery and skill probabilities and are checked against the model's exact bounds; `--seeds` sets only the replay examples of a chart with a luck range. `--stats-cache DIR` keeps the deck model's simulation programs across builds, and entries completed before an interrupted build stay valid; the summary's `deckStats` reports the cache counters (`requests`, `hits`, `computed`, `writes`, `invalid`, `bytes`). `--workers 0` selects the available parallelism.
- **Replay bundle.** `snap-labels.json` (`nnnotes.replay-labels/1`) carries the names, description templates, per-level effects and artwork ids of the Snap and card tables, each bound to the master data's table SHA-256; the manifest names it in `snapLabels`.
- **Schemas.** The JSON Schemas of every document ship with the package: `nnnotes.schemas.names()` and `nnnotes.schemas.load("music-data")`.
- **Fonts.** With `--fonts open` (the default) story, start canvas, host and chat exports read the game's font settings from a table shipped with nnnotes and load no game font bundle.

Validation: Python 3.11, 3.12, 3.13 and 3.14 CI with the deck model, strict golden records, the commit message check, and the wheel installed with `[deck]` in a fresh environment.
